# Implementation plan

1. Repository, Docker Compose and dependency setup.
2. Deterministic energy data, constrained dispatch, and conservation tests.
3. Validated ingestion, database models, migrations and persistent runs.
4. Chronological forecasting and Redis jobs.
5. Battery comparison, outages, explanations and scenario comparisons.
6. Responsive Next.js control center with authoritative simulation playback.
7. Stored-result reports, authentication, authorization and auditing.
8. Integration/browser tests, documentation, measured case studies and public GitHub publication.

Verification results and remaining limits are recorded in docs/VALIDATION.md.
